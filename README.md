# Priyank Diyora - Portfolio

Personal SEO portfolio of Priyank Diyora (SEO Executive, Surat) - built with Next.js (static, no backend) and Tailwind CSS.

Design direction: warm editorial style inspired by two references the owner picked (parthivportfolio.netlify.app as the primary style, blended with elements from nehanooka.netlify.app).

## Sections
Hero (stats + code card) - About - Experience - Skills (SEO & Growth / SEO Tools / Development) - Projects - Education - Contact

## Run
```
npm install
npm run dev
npm run build   # fully static output, no API routes
```

Content lives in `utils/data/*.js` - update details there.
